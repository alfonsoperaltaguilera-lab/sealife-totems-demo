# Demo tótems · Sea Life Benalmádena

Demo comercial de p4Solutions: tótem de especies con agenda de alimentaciones, bajas con aviso,
fichas generadas con IA y panel de gestión. Es una página estática (`index.html`), sin
dependencias; funciona también sin conexión.

El contenido de las fichas es de ejemplo. Las fotos son de Wikimedia Commons y conservan su
licencia (CC BY-SA, GFDL o dominio público); autor, licencia y fuente de cada una aparecen en
la propia demo, pestaña «Tótem».
